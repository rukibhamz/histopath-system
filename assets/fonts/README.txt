Poppins font files
==================

These four .woff2 files ship with the application so every install, including
offline intranet servers, can render Poppins. The stylesheet loads them from
this folder. No Google Fonts request is made.

    poppins-400.woff2    Regular
    poppins-500.woff2    Medium
    poppins-600.woff2    SemiBold
    poppins-700.woff2    Bold
